# 系统架构

## 1. 形式内核

`metamath_generator.parser` 解析 `$c`、`$v`、`$f`、`$e`、`$d`、`$a`
和 `$p`，并将断言分为：

- 语法规则：产生 `term`、`wff` 等类型；
- 逻辑断言：产生 `|- ...`；
- `statement`：只命名目标公式，不声明其为真。

`Node` 是统一的不可变前缀 AST。`Theorem` 保存开放前提、结论、变量类型、
distinct-variable 约束和证明 DAG，并将定理陈述变量与只供证明回放使用的
内部变量分开保存。

## 2. 证明组合

组合器将规则的部分前提与已有证明对象的结论同时合一。被匹配父定理的开放
前提与未匹配规则前提共同进入新对象：

```text
Γ ⊢ A      Δ ⊢ A → B
--------------------
       Γ, Δ ⊢ B
```

所有替换执行 occurs check、精确类型检查和 `$d` 检查。规则变量在应用前
standardize apart，避免与目标变量意外捕获。

## 3. 质量控制

`TheoremGenerator` 维护活动候选、被支配对象和隔离 proof states：

- 语义规范化只用于比较，不改写证明公式；
- 拒绝生成的真空量词和裸模式结论；
- 对相同规范化结论执行前提集合与 `$d` subsumption；
- 奖励闭合、非平凡、含算术结构且证明深度适中的对象；
- 限制连续 alpha 规则和同结论低质量状态数量。

## 4. 神经符号证明

形式 tokenizer 对每个 Metamath 符号和控制指令使用一个原子 token。
Transformer 编码证明状态，并自回归预测规则与显式替换；价值头估计状态
可解性。

混合搜索包含三类候选：

1. 传统证明器枚举的合法规则应用；
2. 由已知定理子结构提出的辅助引理；
3. Transformer 排序或生成的候选动作。

PUCT/MCTS 搜索 AND 型多子目标树。只有最终解路径获得正价值监督，旁支搜索
不会被错误标成成功。

## 5. 证书与验证

搜索动作首先在 `BackwardEnvironment` 中执行。成功路径随后编译为证明
证书，并由项目内 Metamath 验证器按声明顺序和活动作用域重放。模型权重、
MCTS 统计和启发式都不属于符号验证边界。当前内核仅支持未压缩证明；重要
证书仍应由外部 Metamath 实现交叉验证。

## 6. Scale 管线

Scale 数据由已经验证的基础证明模板进行类型保持实例化：

- `term` 变量替换为随机自然数项；
- `wff` 变量替换为随机良构公式；
- 操作符元变量替换为同类型具体操作符；
- 对象变量保持对象变量类型；
- 重新计算 `$d` 约束。

生成器以 gzip JSONL 分片写入，保存候选游标以支持恢复，并在写入层对
state/action ID 进行跨 split 全局去重。训练器支持 bf16、梯度累积、逐层
梯度检查点、上下文课程、周期检查点和精确断点恢复；检查点包含数据流游标、
Python/PyTorch RNG 状态、scheduler、累计计数和完整 metrics 历史。

## 7. 评估边界

当前 Scale 模型的监督目标是：给定证明状态，teacher-forced 预测语料中的下一个
参考动作 token，并用辅助价值头估计状态价值。token accuracy、perplexity 和
exact-reference-action accuracy 都是训练诊断指标，不是最终证明能力指标：

- 合法证明通常不唯一，偏离参考动作仍可能得到正确证书；
- 完全复现参考动作也可能只是记忆模板；
- 长动作只要一个 token 不同，exact-reference-action 就记为失败；
- 单步预测没有测量多步搜索、回溯和开放前提的完全消解。

因此闭环评估必须隐藏参考证明，只提供目标陈述与允许使用的形式库。成功条件
是搜索器构造完整证明 DAG，消解全部开放前提，并由验证器接受证书。主要指标
将是固定节点数/时间预算下的 certified solve rate，并按参考证明深度报告。

## 8. 可选的分解与潜在推理层

形式内核保持不变，候选选择层现提供三个可独立消融的组件：

1. **结构化神经策略**：符号内核产生规则、父定理和开放前提候选，模型只排序
   有限候选，不再自由生成整条替换文本；
2. **闭环策略改进**：MCTS 产生完整搜索轨迹，验证器给出终局奖励，使用
   AlphaZero 式策略改进或 GRPO/PPO 更新模型；
3. **连续潜在思维**：新模型文件在选择动作前循环更新隐藏向量，由停止头决定何时
   输出结构化动作，但潜在向量不能跳过正式规则应用。

此外，`<PROPOSE_LEMMA>` 是受内核检查的显式 cut 动作。对 `Γ ⊢ G` 提议 `L`
会先建立 `Γ ⊢ L`，只有该分支关闭后才激活 `L` 并继续 `Γ,L ⊢ G`。证书编译时
将引理证明内联，因此专用控制 token 和调度标记不会进入 Metamath 证书。

无论神经层如何变化，状态转移始终由 `BackwardEnvironment` 和组合内核执行，
成功轨迹始终必须编译成离散证明证书。详细路线、奖励设计和实验矩阵见
[当前进展与研究路线](progress-and-roadmap.md)。
实现细节和兼容升级命令见[中间引理与连续潜在思维](lemma-and-latent-reasoning.md)。
