# PA+ RTX 3090 长时训练与本地监控

2026-10-03。本次从随机初始化开始，使用 `formal/peano-pa-plus.mm` 和
`formal/pa-plus-definitions.json`，不沿用数论基线数据或修复前动作编码。
这是规模化监督训练，不代表已经证明35个目标，也不是 HTPS latent 模型训练。

## 数据与模型

- 四个随机种子7、11、19、23，各1000次生成尝试；启用全部68个定义、定义桥、
  0–2有界自然数实例、定义覆盖权重3、目标引导权重4。
- 963条去重基础动作；其最大证明深度为5。全量基础动作内核回放须通过后才训练。
- 扩增为1,080,000训练、10,000验证和10,000测试动作，按基础结论族分区、按深度采样，
  状态/动作上限2304 tokens。110万动作不等于110万个不同定理。
- 不能用自由元变量扩增的104条训练集闭式实例保存在独立分片。训练流每8个样本
  使用1条闭式实例；验证/测试保留自然分布，闭式实例不写成重复的“唯一语料”。
- 768维、12头、6层encoder和6层decoder、FFN3072，约105M参数；BF16、梯度检查点、
  AdamW、有效批量8。初始微批量8；测速发生OOM时减半微批量并增加梯度累积。
- 采用已有规模训练的学习率范围1e-4到1e-5；按估计总步数的2%预热。
  损失为动作交叉熵 + 0.25价值MSE + 0.35批内多正例候选损失。
  候选检索准确率和token准确率均不是完整证明成功率。

## 运行与监控

本机实验目录为 `outputs/pa-plus-rtx3090-20261003/`，其中 `prepare.py` 保存本次
可复现的并行生成与去重合并流程；该目录包含大数据和权重，被Git忽略。
准备完成后，入口先全量审计基础动作，再抽样回放1000条扩增动作，再完成80步GPU测速。
正式训练步数按约9小时估算，逐步回调同时执行9小时的时间上限。
因此完成目标步数可能略早；达到时间上限会保存可精确续训的`latest.pt`并停止。

以下命令在仓库根目录运行；用户本次已启动的进程不要重复启动：

```powershell
python tools/run_scale_session.py outputs/pa-plus-rtx3090-20261003 --hours 9
python tools/monitor_training.py outputs/pa-plus-rtx3090-20261003 --port 8765
```

监控为只读本机页面 `http://127.0.0.1:8765/`，每5秒更新训练指标、GPU遥测、
检查点和日志。关闭页面不会停止训练。Windows训练进程在运行期间请求保持系统唤醒，
不修改永久电源设置；关机或显式睡眠仍会中断进程。

- `training-config.json`：测速确定的正式配置。
- `training.jsonl`：逐优化器步的原始损失、吞吐量、样本/token累计数。
- `session.json` / `live.json`：监控状态，原子更新并处理Windows短暂文件占用。
- `model/latest.pt`：每250步及主动停止时保存优化器、调度器、数据游标、RNG。
- `model/final.pt`：完成所有计划步数时产生；时间预算先到时使用`latest.pt`。
- `evaluation-validation.json`：训练结束后512例留出验证评估。
- `base-audit.json` / `audit.json`：全量基础动作与抽样扩增动作审计。

停止时应请求保存，避免直接结束进程：

```powershell
New-Item -ItemType File outputs/pa-plus-rtx3090-20261003/STOP
```

等页面显示停止后，移除该文件才能续训。确认没有同目录训练进程运行，再执行：

```powershell
Remove-Item -LiteralPath outputs/pa-plus-rtx3090-20261003/STOP
python tools/run_scale_session.py outputs/pa-plus-rtx3090-20261003 --hours 9 --resume
```

`--resume`沿用保存的模型配置和原总步数，时间预算包含原训练累计时间；不是重新增加9小时。
监控服务器独立于训练进程，验证完成后仍可查看结果。

## 验证范围

回归覆盖单进程/多进程PA+桥模板扩增、全部抽样动作回放、闭式实例仅训练集重采样、
重采样游标恢复，以及带候选损失的训练主动停止后与连续训练权重逐位一致。
监控页面在桌面和窄屏浏览器中检查；真实GPU测速额外覆盖完整2304-token批次。
本次未做定义族OOD、正式解题率或多随机种子能力对照。
