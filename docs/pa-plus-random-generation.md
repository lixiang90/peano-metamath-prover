# PA+ 随机定理生成：定义桥、有界实例与目标引导

本文记录扩展 PA+ 定义层接入随机定理生成器后的第一轮本地实验。目标不是把随机
拼接得到的公式称为重要数学定理，而是提高以下可测能力：

- 新定义能够作为可验证动作参与后续推导；
- 用小自然数闭式项替换定义参数，提供数学内容明确的起点；
- 只把35个目标公式用于候选排序，不把它们偷渡成定理或公理；
- 随机预算不再主要浪费在明显不可能合一的候选上；
- 68 个新增谓词得到可控、可报告的覆盖；
- 所有保留对象仍带有可导出和重放的 Metamath 证明 DAG。

## 1. 原算法在 PA+ 上的问题

生成器原先只把带 `$e` 前提的逻辑断言当作推理规则。PA+ 的 `df-*` 则是无前提
的等价断言：

```text
df-P $a |- iff P(args) expansion $.
```

它们会进入定理候选库，却没有直接成为“展开 P”或“折叠为 P”的动作。此外，候选
采样过去大多只检查最外层 typecode 是否为 `|-`，再把彼此无关的两个断言交给合一
器，造成大量可预见的失败。

固定 `seed=7`、5,000 步的旧基线为：

| 指标 | 旧基线 |
| --- | ---: |
| 存储证明对象 | 80 |
| 活跃对象 | 76 |
| 合成失败 | 4,498 |
| 新增谓词覆盖 | 19/68（27.94%） |

## 2. 新的定义引导生成

### 2.1 可验证的双向定义桥

启用 `bootstrap_definitions` 后，生成器对目录中每个焦点谓词机械构造两条定理：

```text
|- implies P(args) expansion
|- implies expansion P(args)
```

它们不是额外公理。每一方向分别由已有 `df-P`、`bi1`/`bi2` 和 `ax-mp` 合成，保存
完整证明 DAG。68 个定义因此产生136条桥接定理。统计中将它们单列为
`definition_bridges`，而随机搜索新增量记为 `search_stored`，避免用确定性桥接数量
夸大随机生成效果。

### 2.2 结构兼容候选过滤

候选进入完整合一前先进行保守的树形兼容检查：固定操作符和元数必须相同，类型
相同的叶元变量可作为通配位置。该检查只排除必不可能合一的候选；最终接受仍由
原有类型化 `compose`、occurs check、`$d` 检查和结构上限决定。

### 2.3 modus ponens 联合采样

完整使用 `ax-mp` 时先选择形如 `A -> B` 的主前提，再从结构上可与 `A` 合一的
次前提中采样。不再独立抽两个几乎必然不匹配的 `|-` 断言。联合规划本身不签发
证明，正式合成仍只执行一次。

### 2.4 覆盖均衡

`focus_predicates` 指定本轮希望覆盖的定义集合；CLI 可直接从 PA+ JSON 目录读取。
候选权重按该谓词此前进入生成结论的次数衰减，从而优先补齐欠覆盖定义。输出的
`quality_summary.json` 保存总数、已见数、覆盖率和逐谓词使用次数。

## 3. 使用方法

```powershell
$env:PYTHONPATH='src'
python -m metamath_generator.cli formal/peano-pa-plus.mm `
  --mode random --steps 5000 --seed 7 --max-proof-depth 8 `
  --definition-catalog formal/pa-plus-definitions.json `
  --bootstrap-definitions --definition-coverage-weight 3 `
  --bounded-nat-max 2 --ground-instances-per-predicate 1 `
  --target-guidance-weight 4 `
  --max-definition-only-search-per-predicate 1 `
  --output-dir outputs/pa-plus-guided-seed7
```

这些选项是显式的；仅当 `--bootstrap-definitions` 开启，或闭式实例数大于0而必须
先构造其证明依赖时，才会生成定义桥。结构兼容过滤和 `ax-mp` 联合采样默认启用，
因为它们只改变候选提出顺序，不改变内核接受条件。

## 4. 第一轮结果

| 运行 | 随机步数 | 总存储 | 其中定义桥 | 搜索新增 | 活跃 | 合成失败 | PA+ 覆盖 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 旧 `seed=7` | 5,000 | 80 | 0 | 80 | 76 | 4,498 | 27.94% |
| 新 `seed=7` | 5,000 | 623 | 136 | 487 | 610 | 487 | 100% |
| 新 `seed=11` | 3,000 | 575 | 136 | 439 | 562 | 80 | 100% |
| 新 `seed=19` | 3,000 | 566 | 136 | 430 | 555 | 122 | 100% |

`seed=7` 同预算下总产出约为旧基线的7.8倍，合成失败减少约89%。不同种子的
搜索新增量仍有明显方差，因此这些数据是工程基线，不是算法优越性的统计显著性
结论。

测试还会选择含 PA+ 谓词且证明深度至少为2的随机结果，导出其完整依赖 DAG，
重新解析并逐条由项目验证器重放。双向定义桥也有单独的导出/重放测试。另以
`verify_generated_dag_external` 将同类随机 DAG 交给官方 C Metamath；抽样文件包含
2 条 `$p`，外部验证器报告全部证明通过。

## 5. 有界实例与35目标反向引导

### 5.1 类型安全的有界自然数项实例化

`--bounded-nat-max N` 构造且只构造规范数词
`0, S 0, ..., S^N 0`。`--ground-instances-per-predicate K` 从参数项的有限笛卡尔
积中确定性地选取唯一赋值，对每个定义谓词的展开、折叠桥各生成至多 `K` 个闭式实例。
替换经过与普通组合相同的 parser 类型
检查、同步替换和 `$d` 约束实例化；生成对象的证明仍引用原桥接证明 DAG，不是新增
公理。刻意不把 `1 + 1`、`2 * 1` 等同值表达式纳入这一层，以免语法变体再次造成
表面多样性膨胀。

68 个定义、`N=2`、`K=1` 时产生136条有界实例。因此确定性基础设施合计为
136条定义桥加136条实例；两者都从 `search_stored` 中排除。

### 5.2 目标公式只提供启发式，不提供证明

给出 `--definition-catalog` 时，目录中的35个 `statement` 会作为不可执行目标载入。
CLI 和生成器都检查它们确实属于非逻辑 `statement`；它们不会进入
`logical_assertions`、候选父定理或证明 DAG。每个随机步先从使用较少的目标中采样，
再根据候选结论与目标子公式的固定符号 Jaccard 相似度及目标所需定义谓词召回率增加
采样权重。这是轻量的“从目标往回看”启发式，不是完整 backward proof search。

汇总指标只在随机搜索结果上事后计算，不计定义桥和有界实例：

- `target_statements_touched`：最佳相似度至少为0.25的目标数；
- `target_mean_best_similarity`：35个目标各自最佳相似度的均值；
- `target_best_similarity`：逐目标最佳值，便于定位仍未触达的结构。

### 5.3 限制单一定义包装

生成器沿证明 DAG 追踪所依赖的 `df-*` 定义集合。若随机搜索结果只依赖一个定义、
且结论仍保留该定义谓词，则把它视为“单一定义包装”。
`--max-definition-only-search-per-predicate 1` 将每个谓词此类结果限制为一条；确定性
定义桥和有界实例不受此配额影响。该规则是保守的产量控制，尚不能替代定义完全展开
后的语义等价去重。

### 5.4 固定种子对照

以下均为 `seed=7`、1,000随机步、68个定义桥、`N=2`、每谓词一个有界实例：

| 配置 | 总存储 | 搜索新增 | 触达目标 | 目标平均最佳相似度 | 单定义搜索接纳 | 配额拒绝 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 无目标引导、无配额 | 606 | 334 | 34/35 | 0.600 | 未限制 | 0 |
| 目标权重4、无配额 | 616 | 344 | 35/35 | 0.627 | 未限制 | 0 |
| 目标权重4、每谓词配额1 | 526 | 254 | 35/35 | 0.613 | 64 | 111 |

目标引导在该受控运行中把触达率从34/35提高到35/35；包装配额拒绝了111个候选，
同时保持35/35触达，平均相似度从0.627降至0.613。这是单种子工程证据，尚不构成
统计显著的算法结论。回归测试另在150步固定预算下直接比较同种子的开关两组，要求
引导组的目标触达数和平均最佳相似度都严格改善。

有界实例的完整依赖 DAG 已由项目验证器重放，并由官方 C Metamath 独立验证通过。

## 6. 严格边界和下一步

- 100%覆盖首先表示每个定义都有可用桥接动作，不表示生成器证明了35个目标公式。
- 定义桥是必要的逻辑基础设施，但不应与新发现的数学结果混为一谈。
- 有界实例和目标相似度仍可能产生逻辑恒真式、弱化式或多定义包装；当前配额只解决
  最明显的单定义情形，仍需加入定义完全展开后的语义新颖性指标。
- 随机游走仍主要依赖五条元逻辑规则。下一轮应增加按定义依赖层级的课程采样、
  带开放子目标的真正反向搜索，以及“展开后与已知结论等价”的去重。
- 正式规模语料应报告 `search_stored`、逐深度分布、定义桥占比和多 seed 区间，
  不能只报告包含确定性桥接的总对象数。
- 随机生成 DAG 与神经搜索的扁平 `source_labels` 证书采用不同外部验证入口；接口
  会显式拒绝混用，避免把空证明或错误导出误判为逻辑内核问题。
